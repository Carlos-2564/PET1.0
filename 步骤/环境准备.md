1. 安装 Python（必装）​

下载地址：Python 官网，选择3.8 及以上版本（适配后续库）；​
安装注意：Windows 用户一定要勾选「Add Python to PATH」（否则后续无法在命令行调用 Python），然后点「Install Now」；​
验证是否安装成功：按下Win+R输入cmd打开命令提示符，输入python --version，能显示 “Python 3.x.x” 就说明装对了。

        安装教程可参考如下教程：

PyCharm安装教程及基本使用（更新至2024年新版本），教你迈出学习python第一步-CSDN博客

3.安装 Pillow 库（处理图片用）

pip install pillow
等待出现 “Successfully installed pillow-x.x.x” 就安装完成了，期间如果提示 “pip 不是内部命令”，回去检查第一步是否勾选了「Add Python to PATH」。

4.准备图片资源与文件夹

新建一个文件夹，命名为「桌面宠物项目」（方便管理，建议使用英文命名）；​
在该文件夹内再建一个子文件夹，命名为「gif」（专门放宠物图片）；​
找 3~5 张带透明背景的图片（推荐 GIF透明底动图/表情包），放入gif文件夹（比如动漫角色、卡通形象）。
